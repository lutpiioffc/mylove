# MY LOVELY GIRL 💗 — Website Surat Cinta Interaktif

Website surat cinta romantis dan interaktif yang dirancang khusus untuk dibuka dengan nyaman di layar HP Android maupun PC, 100% offline tanpa memerlukan API Key atau internet tambahan.

## Struktur File
```text
MY-LOVELY-GIRL/
├── index.html   # Struktur halaman pembuka, mini-game hati, surat, dan penutup
├── style.css    # Desain tema pink pastel, putih & ungu + animasi amplop
├── script.js    # Logika mini-game, efek ketikan, galeri foto, & musik romantis
└── README.md    # Panduan membuka website di HP Android
```

## Cara Menjalankan di HP Android
1. Ekstrak file ZIP `MY-LOVELY-GIRL.zip` menggunakan aplikasi File Manager / ZArchiver di HP Android.
2. Buka folder hasil ekstrak, lalu tap file **`index.html`**.
3. Pilih buka dengan **Google Chrome**.
4. Tap tombol **"Mulai Petualangan Cinta 💌"** untuk memulai musik romantis, memainkan kotak misteri hati, dan membaca surat cintanya!
